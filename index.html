MCAT Progress Pal is designed to keep user data inside the user's Chrome profile. The extension does not provide an account, cloud database, analytics service, advertising service, or remote API.

Tracking is off until the user enables it for a supported review site. When tracking is enabled, the extension reads information visible on supported AAMC MCAT Official Prep and Kaplan review pages that is needed to identify and categorize the reviewed question. Depending on the page, this can include:

  • the review page URL and MCAT resource;
  • question number, question text, answer-choice text, explanation or solution text, and site-provided taxonomy labels;
  • whether the answer was correct and the displayed time spent;
  • practice-exam and MCAT-section labels; and
  • notes and error-type selections entered by the user.

Question, passage, answer-choice, explanation, and solution text is processed temporarily on the review page for taxonomy classification. None of that source text, normalized source text, excerpts, evidence fragments, matched aliases, or taxonomy audit trails is saved. The stored review record contains only the final taxonomy assignment and source-free progress metadata. After an update, an idempotent local migration removes any source-evidence and unknown fields from review records created by an earlier version and deletes obsolete generated-question records.

Notes are free-form user-authored fields. The note editor tells users to use their own words and not copy or paste AAMC or Kaplan question, answer, or explanation text. The extension cannot reliably distinguish a user's own writing from text the user manually pastes into a note, so it cannot technically guarantee removal of source content that a user deliberately enters there.

The Equation Recall exercise stores per-equation aggregate progress, including attempt counts, result counts, correct-blank counts, streak, and the time and result of the latest attempt. Individual typed answers and complete exercise sessions are not persisted.

Dashboard statistics are calculated locally from stored review and exercise records. The extension also stores local preferences such as per-site tracking settings, the floating-panel mode and position, taxonomy-version selections, and acknowledgement of the tracking privacy disclosure.

All persistent user data is stored with chrome.storage.local. This storage belongs to MCAT Progress Pal within the current Chrome profile. The extension does not use chrome.storage.sync, page localStorage, sessionStorage, IndexedDB, cookies, or a remote database.

Data remains until the user deletes it from Dashboard > Settings > Data & Privacy, clears the extension's data through Chrome, or uninstalls the extension. Turning tracking off stops new review-page collection but does not delete existing records.

Chrome profiles are the privacy boundary. A different person installing the extension in another Chrome profile or on another device cannot access this profile's extension storage through MCAT Progress Pal. People who share the same Chrome profile, or who can access the device, Chrome profile files, extension developer tools, backups, or an administrator account, may be able to access local data.

MCAT Progress Pal does not transmit user data outside the browser. It makes no requests to an external API, analytics provider, advertising network, cloud database, or publisher server.

The extension loads its equation dataset, taxonomy datasets, scripts, and styles from files packaged inside the extension. These are chrome-extension:// resources, not network services. Exported CSV files are created locally and downloaded only at the user's request.

Notes are handled within the extension and are not made available to the supported website by MCAT Progress Pal.

MCAT Progress Pal uses review-page information and user-entered data only to provide its user-facing question categorization, notes, exercises, exports, and progress analytics. The data is not sold, shared, used for advertising, or used to determine creditworthiness or lending eligibility. Because the extension does not transmit this data to the publisher or another service, the publisher and other people are not given access to read it through MCAT Progress Pal.

MCAT Progress Pal uses this information only to provide the extension's disclosed functionality, including question categorization, notes, exercises, exports, and progress analytics.

The extension requests the Chrome storage permission to save the data described above. Its content scripts run only on the supported AAMC MCAT Official Prep and Kaplan host patterns declared in the extension manifest. Site access allows the extension to read the relevant review-page content locally when tracking is enabled.

Users can keep tracking off, turn it on or off separately for supported review contexts, choose when the private floating panel appears, export notes to a local CSV file, and permanently clear all extension data from Dashboard > Settings > Data & Privacy.
